## A1. 玻璃嵌套玻璃

- **违反**：平台设计语言硬规则（Apple Liquid Glass）
- **表现**：导航栏的玻璃容器里，又套了一层玻璃卡片 / 玻璃按钮 / 玻璃弹层
- **判定**：检查是否存在「玻璃层内含玻璃子元素」——多层 `backdrop-filter` / `blur` 嵌套；有即违规
- **根因**：Liquid Glass 只属于**导航层**，嵌套会叠加模糊、破坏层级与可读性
- **修正**：内层元素改用实色或语义 token `surface/raised`

## A2. 文字直接压玻璃

- **违反**：平台设计语言硬规则
- **表现**：标题 / 正文直接渲染在玻璃层上
- **判定**：文字节点是否位于玻璃层内且无实色底 / scrim；是即违规
- **根因**：玻璃透明度随背景内容动态变化，文字对比度不可控，必然在某种背景下不可读
- **修正**：文字移到实色层；确需覆盖时在玻璃上加实色 scrim

## A3. Bento 网格 + 渐变光晕堆砌

- **违反**：俗套校准表
- **表现**：首屏 ≥3 个等宽卡片 + 紫粉蓝大面积 blur blob 背景 + 圆角图标居中
- **判定**：首屏等宽卡片数 ≥3 **且** 存在大面积模糊渐变背景；命中即需换轴或说明
- **根因**：2026 最流行的模板组合，零差异化，是「AI 味」的典型来源
- **修正**：换轴（改布局 / 加签名元素）；仅当 Brief 明示要求时才采用，且须写出理由

## A4. 无权限显示「暂无数据」

- **违反**：交互规范 · 边界状态
- **表现**：权限校验失败时，界面复用了空数据的文案（如「暂无数据」「还没有内容」）
- **判定**：权限失败路径的文案是否**等于**空态文案；相等即违规
- **根因**：空数据与无权限语义完全不同，复用会误导用户以为数据不存在，从而放弃申请权限
- **修正**：无权限态必须说明**缺什么权限** + **如何获取**（申请入口 / 联系管理员）

## A5. 裸转圈超过 1s

- **违反**：交互规范 · 感知时延 + 状态机
- **表现**：结构化内容加载时使用 spinner，且无骨架屏
- **判定**：Loading 态是否为纯 spinner **且** 预期时长 >1s；是即违规
- **根因**：>1s 无进度指示会打断注意力流；骨架屏能同时传递「内容结构」与「正在加载」两个信息
- **修正**：结构化内容一律用**骨架屏**（尺寸与真实内容对齐）；可确定进度时用进度条

## A6. 图标单独承载语义

- **违反**：图标规范
- **表现**：只有图标、没有文字的按钮，且无 `aria-label` / `Semantics` / Tooltip
- **判定**：图标按钮是否缺 `aria-label` / `Semantics` / 文字标签 / Tooltip；缺即违规
- **根因**：同一图标在不同语境含义不同（如「书签」可能被读成「收藏/标记/保存」），且无障碍工具无法朗读
- **修正**：补文字标签，或补 `aria-label`（Web）/ `Semantics`（App）

## A7. 同屏混用 AI 图与矢量插图

- **违反**：贴图规范 · 三条硬约束
- **表现**：同一屏内既有 AI 生成位图，又有扁平矢量插画
- **判定**：单屏内图像**来源种类** >1；是即违规
- **根因**：来源混用是廉价感最大的来源，两种质感无法调和
- **修正**：按角色统一——氛围类用 AI、功能类用矢量，**同屏只用一种来源**；两种来源统一施加 duotone

## A8. 组件层硬编码色值

- **违反**：三层 Token 架构
- **表现**：组件文件里直接写 `#RRGGBB` / `rgb()` / 字面 `px` 值，而非引用语义 token
- **判定**：`grep -rn "#[0-9A-Fa-f]\{6\}" <组件目录>` —— 组件层命中即违规
- **根因**：破坏主题切换（暗色/高对比）与全局一致性，改一处漏一处
- **修正**：改用语义 token（`color/surface/default` 等）；原始数值只允许出现在原始层定义处

## A9. Barely-there 滑成「无层级」

- **违反**：俗套校准表（Barely-there 极简克制）
- **表现**：近白底 + 全灰阶 + 单一字重 + 一级字号，主 CTA 与正文同权；留白成了唯一的层级手段
- **判定**：全页仅 1 种字重且字号种类 ≤2，或主 CTA 与正文视觉权重相同；命中即违规
- **根因**：极简的有效性来自字阶/对比/间距节奏，砍掉层级后只剩「空」，退化为 AI 默认模板
- **修正**：保留留白，补 3 级字阶 + 1 处字重或强调色对比；建不起层级则换轴

## A10. Anti-grid 滑成「装饰性错位」

- **违反**：俗套校准表（Anti-grid 刻意破碎网格）+ 通用自检「结构诚实」
- **表现**：元素随机旋转/浮移/越界遮挡，与内容分组无关；错位元素看着可点击却无交互
- **判定**：每处错位须能口头说出编码了什么（顺序/分组/优先级），说不出即视为未编码；或带交互样式但无 hover/focus 反馈；命中即违规
- **根因**：错位只有编码结构才成立，纯装饰错位会被读成层级错误或交互线索，破坏可读性
- **修正**：让错位承载分组/强调，并保证焦点不被遮挡（WCAG 2.4.11）、交互元素有 hover/focus；否则回正交网格
